1. 시작하기

교회회계 앱은 교회의 수입·지출, 계좌, 교인 명부, 기부금영수증을 한 곳에서 관리하는 웹앱(PWA)입니다. 스마트폰과 PC 브라우저 모두에서 사용할 수 있습니다.

로컬 버전은 입력한 모든 데이터를 지금 사용하는 기기(브라우저) 안에만 저장합니다. 클라우드(서버)로 보내거나 다른 기기와 자동으로 맞추는 기능이 없습니다. 대신 인터넷 계정이나 로그인 없이 바로 쓸 수 있고, 재정 데이터가 외부로 나가지 않습니다.

⚠️ 데이터가 이 기기에만 있으므로 백업이 곧 보험입니다. 시작하기 전에 2장과 16장(백업)을 꼭 읽어 주세요.

앱으로 설치하기

  • 안드로이드(크롬): 처음 접속하면 앱으로 설치하기 배너가 나타납니다. 설치를 누르세요. 배너를 닫으면(✕) 다시 나타나지 않습니다.
  • 아이폰(사파리): 공유 버튼 → 홈 화면에 추가를 선택합니다.
  • PC(크롬·엣지): 주소창 오른쪽의 설치 아이콘을 눌러 설치하거나, 그냥 브라우저 탭으로 열어 써도 됩니다.
  • 설치하면 홈 화면 아이콘으로 실행되고 화면이 꽉 차게 보입니다.
💡 한 가지 방법으로만 쓰세요. 브라우저 탭으로 열었을 때와 홈 화면에 설치한 앱은 저장 공간이 다를 수 있습니다. 어느 쪽에 입력했는지 헷갈리지 않도록 처음부터 한쪽(권장: 설치한 앱)만 사용하세요.

2. 로컬 버전, 꼭 알아둘 점

데이터는 어디에 저장되나요?

입력한 거래·항목·명부·계좌·교회 정보·직인은 이 기기의 브라우저 저장소(IndexedDB)에 들어갑니다. 인터넷이 끊겨도 입력과 조회가 가능하고, 입력 즉시 저장되므로 별도의 저장 버튼은 없습니다.

이런 점이 클라우드 버전과 다릅니다

항목로컬 버전
저장 위치지금 쓰는 기기·브라우저 안에만 저장
다른 기기와 동기화없음. 폰에서 입력한 내용이 PC에 자동으로 나타나지 않습니다.
클라우드 로그인·업로드·다운로드없음 (설정 탭에 해당 메뉴가 나오지 않습니다)
비밀번호이 기기에만 저장되고, 기기마다 따로 정합니다.
데이터 옮기기JSON 백업 파일로 내보내고 가져오기 (17장)

데이터가 사라지는 경우

  • 브라우저의 인터넷 사용 기록·사이트 데이터·쿠키 삭제를 선택했을 때
  • 설정의 모든 데이터 초기화를 실행했을 때
  • 기기를 분실·초기화·교체했을 때
  • 시크릿(비공개) 창에서 입력했을 때 — 창을 닫으면 사라집니다. 시크릿 창에는 평소 쓰던 데이터도 보이지 않습니다.
  • 아이폰 사파리에서 오래 사용하지 않은 사이트는 저장 데이터를 정리할 수 있습니다. 홈 화면에 추가해서 사용하고, 주기적으로 백업하세요.

같은 데이터를 보려면

같은 기기라도 다른 브라우저(예: 크롬 ↔ 엣지)나 앱 주소가 다른 곳에서 열면 빈 화면이 나옵니다. 항상 같은 브라우저(또는 설치한 앱)에서 같은 주소로 여세요.

개인정보는?

금액, 이름, 주민번호 등 입력한 재정·명부 데이터는 외부 서버로 전송되지 않습니다. 다만 앱이 사용되었다는 방문 기록(접속 횟수) 통계만 개발자에게 집계되며, 거래 내용은 포함되지 않습니다.

⚠️ 주민번호가 담긴 기기는 화면 잠금을 설정하고, 백업 파일(JSON)도 안전한 곳에 보관하세요. 백업 파일 자체는 암호화되어 있지 않습니다.

3. 처음 시작하기 체크리스트

앱을 처음 열면 빈 화면에 기본 항목과 대표계정만 만들어져 있습니다. 아래 순서대로 준비하면 바로 입력할 수 있습니다.

  1. 비밀번호 설정 — 설정 탭에서 4자 이상으로 등록합니다. (4장)
  2. 앱 이름 변경 — 설정의 앱 이름에서 교회 이름으로 바꿉니다.
  3. 연결계좌 확인·추가 — 설정 → 연결계좌 관리에서 대표계정의 이름을 맞추고, 정기예금 등이 있으면 정기계정을 추가한 뒤 이월금액을 입력합니다. (11장)
  4. 수입 항목 '헌금' 만들기 — 아래 설명을 보세요.
  5. 지출 항목 정리 — 기본 항목을 교회 실정에 맞게 수정·추가합니다. (15장)
  6. 교인 명부 등록 — 명부 탭에서 교인을 추가합니다. (12장)
  7. 교회 정보·직인 등록 — 기부금영수증을 발행할 경우에만 필요합니다. (13장)
  8. 첫 백업 — 설정이 끝나면 JSON 백업을 한 번 받아 둡니다. (16장)

기본으로 들어 있는 항목

구분대분류 (세부항목)
수입이자(예금이자·적금이자·기타이자), 기타(잡수입·환급금·후원금)
지출인건비, 시설비, 선교비, 운영비, 예금

이 항목들은 자유롭게 이름을 바꾸거나 지우고, 새로 추가할 수 있습니다.

수입 대분류 '헌금' 만들기 (중요)

기본 항목에는 헌금이 없습니다. 교인 이름별 헌금 입력, 헌금 일괄 입력, 개인별 헌금 엑셀, 기부금영수증은 모두 이름이 정확히 '헌금'인 수입 대분류를 기준으로 동작합니다.

  1. 설정 → 수입/지출 항목 관리에서 수입 쪽의 + 새 대분류 추가를 누릅니다.
  2. 이름에 헌금을 입력합니다. (띄어쓰기·다른 글자를 붙이지 마세요)
  3. 하위항목 사용 스위치를 켭니다. (헌금 → 교인 이름 선택 → 세부항목 입력 구조가 됩니다)
  4. 저장한 뒤 다시 열어 세부항목 관리에서 십일조, 감사헌금, 주일헌금, 선교헌금 등 헌금 종류를 추가합니다.
💡 교인 이름(중분류)은 명부 탭에서 교인을 등록하면 헌금 입력 화면에서 선택할 수 있습니다. 입력 중에 + 중분류 추가로 바로 만들 수도 있습니다.

4. 입력 모드와 비밀번호

이 앱은 두 가지 모드로 동작합니다.

모드할 수 있는 일
🔒 열람 전용 모드내역·통계·계정 조회만 가능. 입력/수정/삭제와 설정 변경은 막힙니다.
🔓 입력 모드데이터 입력, 수정, 삭제, 설정 변경, 백업 복원이 모두 가능합니다.

입력이 필요한 기능을 열람 모드에서 누르면 "🔒 입력 모드에서만 사용 가능합니다" 안내가 나옵니다.

처음 비밀번호 설정

  1. 설정 탭의 🔑 비밀번호 최초 설정 칸에 사용할 비밀번호를 입력합니다. (4자 이상)
  2. 비밀번호 설정 버튼을 누르면 등록과 동시에 입력 모드로 전환됩니다.
  3. 눈 아이콘(👁)을 누르면 입력한 글자를 확인할 수 있습니다.

로그인 / 로그아웃

  • 로그인: 설정 탭의 비밀번호 칸에 입력 후 로그인. 입력이 필요한 기능을 눌렀을 때 뜨는 비밀번호 창으로도 로그인할 수 있습니다.
  • 로그아웃: 입력 모드에서 로그아웃을 누르면 열람 모드로 돌아갑니다.
  • 한 번 로그인하면 앱을 닫았다 열어도 입력 모드가 유지됩니다. 여러 사람이 쓰는 기기에서는 사용 후 꼭 로그아웃하세요.

비밀번호 변경

  1. 입력 모드에서 비밀번호 변경을 누릅니다.
  2. 현재 비밀번호 확인 → 새 비밀번호(4자 이상) 입력 → 새 비밀번호 재입력 → 변경 저장.

비밀번호를 잊어버렸다면

로컬 버전에는 비밀번호를 찾아주는 기능이 없습니다. 비밀번호는 이 기기 안에만 있기 때문입니다. 아래 순서로 처음 상태로 돌린 뒤 백업을 복원하세요.

  1. 가장 최근 백업 JSON 파일이 있는지 먼저 확인합니다. 없다면 아래 방법은 모든 데이터가 지워지므로 시도하지 마세요.
  2. 브라우저 설정에서 이 앱 주소의 사이트 데이터(저장 데이터)를 삭제합니다. 설치한 앱이면 앱을 삭제한 뒤 다시 설치합니다.
  3. 앱을 다시 열어 새 비밀번호를 설정합니다. (처음 설정과 같은 방법)
  4. 데이터 가져오기로 백업 파일을 복원합니다. 백업에는 비밀번호가 포함되지 않으므로 새로 정한 비밀번호가 그대로 유지됩니다.
⚠️ 이 비밀번호는 입력 실수를 막는 잠금이지 데이터를 암호화하지는 않습니다. 기기를 다른 사람이 마음대로 쓸 수 있다면 기기 자체의 화면 잠금도 함께 사용하세요.

5. 홈 화면

요약 카드

파란색 카드에 선택한 달의 요약이 표시됩니다. 카드 위의 ‹ › 화살표로 월을 이동합니다.

  • 전년이월: 지난해에서 넘어온 금액
  • 총수입 / 순지출 / 순수입계: 이번 달 합계 (통장이동은 수입·지출에서 구분되어 처리됨)
  • 총예금: 예금(정기계정) 관련 합계

보기 방식 3가지

보기설명
달력달력 형태로 날짜별 수입(초록)·지출(빨강)을 한눈에 봅니다. 날짜를 누르면 그날의 상세가 열립니다.
일일날짜별로 묶은 거래 목록. "오늘", "어제"로 표시됩니다.
월별월 단위로 모아 본 목록입니다.

내역이 없으면 "이번 달 내역이 없어요"와 함께 ＋ 버튼 안내가 나옵니다. 다른 계좌로의 이체는 ↔ 계좌이체로 표시됩니다.

하루 상세(날짜 패널)

달력에서 날짜를 누르면 그날의 거래 목록이 열립니다.

  • 위쪽 버튼으로 수입·지출을 새로 추가
  • 📊 헌금 일괄 입력 (여러 명 한 번에) 버튼으로 주일 헌금을 한꺼번에 입력 (7장 참고)
  • 이 날 거래가 없으면 "이 날의 내역이 없어요"가 표시됩니다.
  • 계좌 선택 시 🚫 안 쓰는 계좌 숨기기 관리로 쓰지 않는 계좌를 목록에서 숨길 수 있습니다. (대표계정은 숨길 수 없음)

6. 거래 입력·수정·삭제

거래는 대분류 → (중분류: 이름) → 세부항목별 금액 3단계로 입력합니다.

새 거래 입력 순서

  1. 홈의 ＋ 버튼 또는 날짜 패널에서 수입/지출을 선택해 새 거래 창을 엽니다.
  2. 항목 선택: 대분류를 고릅니다. (예: 헌금, 관리 및 유지비 등)
  3. 이름 선택: 대분류가 헌금처럼 사람 이름을 쓰는 경우, 목록에서 이름을 고릅니다.
    • 검색창에 이름 또는 초성(예: ㄱㄷㅎ)을 입력하면 빠르게 찾습니다.
    • 없는 이름은 + 중분류 추가로 즉시 추가합니다.
  4. 세부항목별 금액 입력: 십일조, 감사헌금처럼 세부항목마다 금액을 입력합니다. 자주 쓰지 않는 항목은 ▶ 추가 항목 더보기를 눌러 펼치고, 필요하면 새 세부항목 추가로 만듭니다.
  5. 필요하면 메모(선택)를 적고, 날짜와 계좌를 확인한 뒤 저장합니다.
💡 한 번 입력 화면에서 금액을 여러 세부항목에 동시에 입력해 저장할 수 있습니다. 최소 1개 항목에는 금액이 있어야 저장됩니다.

새 항목 추가

  • 항목 선택 화면의 + 새 항목 추가 / + 새 대분류로 즉석에서 추가할 수 있습니다.
  • 대분류를 먼저 고른 뒤 중분류(이름) 추가 또는 소분류 추가 중 하나를 선택합니다.
  • 이미 있는 이름은 "이미 있는 이름이에요"라며 막힙니다.

안 쓰는 이름 숨기기

이름 선택 화면의 🚫 안 쓰는 이름 숨기기 관리에서 체크한 이름은 헌금 입력 목록에서 보이지 않습니다. 명부의 숨김교인 설정과 같은 값이라 한 곳에서 바꾸면 양쪽에 반영됩니다.

계좌 선택과 통장이동

  • 계좌 구분: 일반계정, 정기계정. 대표계정은 기본으로 선택됩니다.
  • 통장이동은 계좌 사이 자금 이동으로, 수입·지출 통계와 분리되어 처리됩니다.
  • 계좌가 없다면 설정 > 연결계좌 관리에서 먼저 추가하세요.

수정 · 날짜 변경 · 삭제

  • 수정: 내역에서 거래를 눌러 내용을 고치고 수정 완료.
  • 날짜 변경: 날짜 선택 창에서 새 날짜를 골라 적용합니다.
  • 삭제: "이 거래를 삭제할까요?"에서 확인하면 삭제됩니다. 되돌릴 수 없으니 신중히 하세요.

7. 헌금 일괄 입력

주일 헌금처럼 여러 교인의 헌금을 한꺼번에 입력하는 엑셀형 화면입니다.

  1. 홈에서 입력할 날짜를 눌러 날짜 패널을 엽니다.
  2. 📊 헌금 일괄 입력 (여러 명 한 번에)을 누릅니다.
  3. 가로는 헌금 종류, 세로는 교인 이름인 격자에서 해당 칸에 금액을 입력합니다.
  4. 맨 아래 일괄 저장을 눌러 한 번에 저장합니다.
⚠️ 입력 단위는 천원입니다. (예: 50000원 → 50) 저장 전 화면 상단의 "명 · 총" 합계를 꼭 확인하세요.

화면 상단 버튼

버튼기능
👥 교인 가리기체크한 교인을 이 화면과 개별 헌금 입력 목록에서 숨깁니다. (명부의 숨김교인과 같은 설정)
🏷️ 항목 가리기체크한 헌금 종류를 이 일괄 입력 화면에서만 숨깁니다. 개별 입력 화면에는 그대로 보입니다.
🗑️ 입력삭제저장하지 않은 입력 내용을 모두 지웁니다. 지운 뒤에는 복구할 수 없습니다.
일괄 저장입력한 모든 금액을 거래로 저장합니다. 금액이 한 칸도 없으면 저장되지 않습니다.

반복 금액 자동 채우기

개별 입력에서 🔄 반복 등록한 교인(매주 같은 금액을 내는 분)은 일괄 입력 화면에서 이름이 파란색으로 표시됩니다. 이름을 탭하면 등록된 반복 금액이 그 행에 자동으로 채워집니다. 안내 문구: "파란 이름 탭 → 반복 적용"

💡 표시할 교인이나 헌금 종류가 없다고 나오면, [교인 가리기]/[항목 가리기]의 숨김을 풀거나 명부 탭에서 교인을 추가하세요.

8. 반복 등록

같은 사람이 같은 금액을 규칙적으로 내는 경우 한 번만 등록해 두면 편합니다.

  1. 거래 입력 화면에서 세부항목 금액을 입력합니다.
  2. 🔄 반복 등록을 누르면 "반복 등록됐어요" 메시지와 함께 저장됩니다.
  3. 다음부터 같은 이름·대분류로 입력할 때 🔄 반복 적용으로 금액을 한 번에 채웁니다.
  4. 더 이상 필요 없으면 반복 해제.

반복 템플릿은 대분류 + 이름 조합마다 1개씩 저장됩니다. 금액을 먼저 입력하지 않고 반복 등록을 누르면 "금액을 먼저 입력해주세요"가 표시됩니다.

9. 예산 탭

연도별 예산과 실제 집행 현황을 비교합니다.

  • 연도 선택으로 해당 연도를 봅니다.
  • 구분: 전체 요약 / 수입 예산 / 지출 예산. 각각 합계와 집행률(%)이 표시됩니다.
  • 예산이 없으면 "설정된 예산이 없어요"가 표시됩니다. 헌금종류별 예산은 항목 관리에서 소분류 예산을 설정해야 합니다.
  • 항목 관리 버튼으로 항목 구조와 예산 금액을 편집합니다. (15장 참고)

다음 해 예산 편성 (엑셀 양식)

  1. 예산 탭의 📥 예산양식을 눌러 엑셀 양식(예산편성_연도.xlsx)을 내려받습니다.
  2. 엑셀에서 노란 칸(중분류·소분류의 다음해예산)에만 금액을 입력합니다.
  3. 대분류·중분류 합계 칸은 수식으로 자동 계산되므로 직접 입력하지 마세요. 구분/대분류/중분류/소분류 열은 지우거나 순서를 바꾸면 안 됩니다.
  4. 앱에서 설정 → 예산 데이터 가져오기로 파일을 올립니다.
  5. "예산으로 반영할까요?"에서 확인하면, 값이 채워진 항목만 업데이트되고 나머지는 그대로 유지됩니다.
⚠️ 앱에서 내려받은 양식이 아니면 "양식을 인식할 수 없습니다" 오류가 납니다.

10. 통계 탭

선택한 기간의 수입·지출을 분석합니다. 화면 위에서 통계와 내용 보기를 전환합니다.

보기내용
통계대분류별 지출, 개인별 헌금액 등을 막대로 보여줍니다. 항목을 누르면 상세 내역이 열립니다.
내용헌금종류·대분류/소분류 단위 집계. 집계 항목을 누르면 상세가 열립니다.
리스트기간에 맞춘 거래 목록
이자선택 기간의 이자 내역과 이자합계. 이자가 없으면 "선택한 기간의 이자 내역이 없습니다"

기간 설정

주간 / 월간 / 연간 / 기간설정 중에서 고릅니다. 기간설정은 시작일과 종료일을 직접 지정합니다.

내보내기와 인쇄

  • 📥 엑셀: 통계를 엑셀 파일로 내려받습니다. (개인별헌금, 월지출, 월장부 형식 등)
  • 🖨️ 인쇄: A4 용지에 맞춘 통계 인쇄물을 만듭니다.

요약 숫자(전년이월, 통장이동, 이월잔액, 순지출, 순수입계)도 함께 표시됩니다.

11. 계정 탭

계좌별 잔액과 입출금을 관리합니다. 크게 일반계정과 정기계정으로 나뉩니다.

  • 이월금: 연초 이월 잔액 / 수입금 · 지출금: 해당 연도 합계
  • 자산합계, 정기계정 합계, 계좌 합계가 표시됩니다.
  • 정기계정에는 만기일이 함께 표시됩니다.
  • 연도 선택으로 연도를 바꾸거나 전체 연도로 누적을 봅니다.
  • 계정을 누르면 그 계좌의 거래 내역(재정→/→재정 이체 포함)이 열리고 📥 엑셀, 🖨️ 인쇄도 가능합니다.

등록된 계좌가 없으면 "설정 → 연결계좌 관리에서 추가하세요"가 표시됩니다.

연결계좌 추가·편집 (설정 > 연결계좌 관리)

  1. 계좌 추가 → 일반계좌 또는 정기계정 선택. (빠른 선택: 정기선교, 정기건축, 정기후대, 정기퇴직 등)
  2. 계좌 이름 입력 (예: 재정계정, 선교계정). 같은 이름은 만들 수 없습니다.
  3. 이월금액(원) 입력. 이전 기간에서 넘어온 금액입니다.
  4. 정기계정이면 만기일 입력(선택).
  5. 필요하면 대표계정으로 설정. 대표계정은 날짜 패널에서 기본 선택됩니다.
  6. 잘못 만든 계좌는 계좌 삭제로 지웁니다.

12. 명부 탭

교인 명부를 관리합니다. 명부에 등록하면 헌금 입력 시 이름으로 선택할 수 있습니다.

  • 필터: 전체교인 / 정교인 / 숨김교인
  • 정렬: 이름순 등
  • + 추가로 새 교인 등록, 목록의 교인을 눌러 수정
  • 엑셀로 내보내기 (교인명부 파일), 인쇄용 교인 명부 출력

교인 정보 입력 항목

구분항목
기본 정보이름(필수), 직분(예: 집사, 권사, 장로), 주민번호, 전화번호
가족 정보가족 그룹(예: 홍길동 가족), 세대(1~4세대), 가족 대표자
표시 설정숨김 여부 — 숨기면 헌금 입력 목록에서 빠집니다
⚠️ 교인을 삭제해도 기존 거래 데이터는 유지됩니다. 단, 이후 명부에서는 보이지 않습니다. 교회를 옮기셨거나 더 이상 입력하지 않는 교인은 삭제보다 숨김 처리를 권장합니다.
⚠️ 주민번호는 기부금영수증 발행에 사용되는 민감한 정보입니다. 입력 모드 비밀번호를 안전하게 관리하고, 공용 기기에서는 반드시 로그아웃하세요.

13. 기부금영수증

명부 탭의 기부금 버튼으로 들어갑니다. 소득세법 시행규칙 [별지 제45호의2서식] 형식으로 발행됩니다.

사전 준비 (설정 탭)

  • 교회 정보: 단체명, 사업자등록번호, 소재지 등을 입력합니다. 미입력 시 "교회 정보가 입력되지 않았어요" 안내가 나옵니다.
  • 직인(도장) 이미지: 배경이 투명한 PNG 권장, 2MB 이하. 미등록 시 "등록된 직인이 없어요" 안내가 나옵니다.

발행 방법

  1. 주 신청인(필수, 1명)을 이름 검색으로 고릅니다.
  2. 가족 합산이 필요하면 합산 대상 추가로 다른 교인을 더합니다.
  3. 귀속 연도와 발급일자를 선택합니다.
  4. 합산 금액을 확인합니다.
  5. 미리보기로 서식을 확인한 뒤 아래 중 하나를 선택합니다.
    • 🖨️ 인쇄 — 프린터로 출력
    • ⬇️ PDF로 저장 — 파일명 기부금영수증_이름 형식
    • 📤 공유하기 — 메일·카톡·문자 등으로 공유. 기기가 공유를 지원하지 않으면 PDF로 대신 저장됩니다.
💡 PDF 저장은 PDF 라이브러리가 필요합니다. "PDF 라이브러리를 불러오지 못했습니다"가 나오면 인터넷 연결을 확인하고 새로고침하세요.

정기계정 만기 알림 사용법

  2. 설정 → 알림 수신 이메일에서 이메일 주소를 저장합니다.

  4. 수동 확인은 지금 바로 만기 체크 → 📧 메일로 발송하기입니다.

메일 앱이 설정되어 있지 않은 기기에서는 메일 작성 화면이 열리지 않을 수 있습니다.

15. 항목(분류) 관리

설정의 수입/지출 항목 관리 또는 예산 탭의 항목 관리에서 편집합니다. 구조는 3단계입니다.

  • 대분류: 예) 헌금, 관리 및 유지비, 선교비
  • 중분류: 예) 자동차, 교회당 / 헌금에서는 교인 이름이 들어갑니다
  • 소분류: 예) 자동차보험, 주유비 / 헌금에서는 십일조, 감사헌금 등 헌금 종류

할 수 있는 작업

  • + 새 대분류 추가, 중분류/소분류 추가·이름 수정
  • 소분류에 예산 금액 입력 (예산 편집 연도를 선택해 연도별로 설정)
  • 기본 항목 / 일반 항목 전환 — 기본 항목은 거래 입력 시 먼저 보이고, 나머지는 추가 항목 더보기에 들어갑니다.
  • 항목 삭제 시 거래가 있는 항목이면 다른 항목으로 이동할지 묻는 화면이 열립니다.
  • 🕘 예전 항목 보기: 연도별로 저장된 이전 항목 구조를 조회합니다.
💡 헌금 대분류는 교인이 수백 명이어도 항목구조표에 사람별로 펼치지 않고, 헌금 종류(소분류)만 중복 없이 모아서 보여줍니다. 명부 등록·개인별 입력·통계에는 영향이 없습니다.

16. 백업과 복원

⚠️ 로컬 버전의 데이터는 백업 파일이 유일한 사본입니다. 최소한 월말마다 백업하고, 백업 파일은 USB·구글 드라이브·이메일 등 기기 밖의 다른 곳에도 보관하세요.
기능설명
데이터 백업 (JSON)전체 / 개별 달 / 범위 설정 중에서 골라 JSON 파일(backup-…json)을 받습니다. 파일 이름은 비워 두면 자동으로 정해집니다. 열람 모드에서도 받을 수 있습니다.
자동 백업켜 두면 매주 월요일 정오 이후에 앱을 열었을 때 하루 1번 autobackup_날짜.json이 만들어집니다. 앱을 열지 않으면 실행되지 않습니다. 거래가 1건도 없으면 만들지 않습니다. 마지막 백업일이 설정 화면에 표시됩니다.
백업 위치PC의 크롬·엣지에서는 폴더를 지정하면 그 폴더에 바로 저장됩니다. 폴더 지정이 안 되는 기기(아이폰, 일부 안드로이드)는 기기의 다운로드 폴더에 저장됩니다. 폴더 설정은 기기마다 따로 해야 합니다.
백업 메일 발송입력 모드에서 사용합니다. 스마트폰에서는 공유 창이 열려 메일·메신저로 파일을 바로 보낼 수 있고, PC에서는 JSON이 다운로드된 뒤 메일 작성 화면이 열리니 파일을 직접 첨부해서 보냅니다. 알림 이메일을 먼저 등록해야 합니다.
엑셀로 내보내기거래 내역을 xlsx로 받습니다. 엑셀은 보고용이며 복원에는 쓸 수 없으므로 백업은 JSON으로 받으세요.
데이터 가져오기입력 모드에서 백업 JSON 파일로 복원합니다. 🔒 열람 모드에서는 사용할 수 없습니다.
예산 데이터 가져오기예산 양식 엑셀의 다음해 예산을 반영합니다. (9장)

백업에 들어 있는 것

  • 거래, 항목(대·중·소분류), 교인 명부, 연결계좌, 반복 등록 템플릿
  • 교회 정보, 직인 이미지, 앱 이름 등 설정
  • 비밀번호는 들어 있지 않습니다. 복원해도 비밀번호는 바뀌지 않습니다.

백업 습관 만들기

  1. 매월 마감 후 데이터 백업 (JSON) → 전체를 선택해 받습니다.
  2. 파일 이름 뒤에 날짜를 붙여 보관하면 찾기 쉽습니다. (예: 백업_2026-11-30.json)
  3. 받은 파일을 다른 기기·클라우드 폴더·이메일 등 최소 한 곳 이상에 더 복사합니다.
  4. 자동 백업도 함께 켜 두면 이중 안전장치가 됩니다.
  5. 앱 업데이트, 브라우저 정리, 기기 교체 직전에는 반드시 한 번 더 백업합니다.

복원 순서

  1. 입력 모드로 로그인합니다.
  2. 설정 → 데이터 가져오기를 누르고 백업 JSON 파일을 선택합니다.
  3. 안내 창의 항목·거래 수를 확인합니다. 기존 데이터가 백업 내용으로 교체됩니다.
  4. 완료 후 화면이 새로고침되면 홈·통계에서 금액이 맞는지 확인합니다.
💡 복원 전에 현재 상태도 한 번 백업해 두면, 잘못 복원했을 때 되돌릴 수 있습니다.

17. 기기 바꾸기 · 여러 기기에서 쓰기

새 기기로 옮기기

  1. 이전 기기에서 데이터 백업 (JSON) → 전체 백업을 받고, 파일을 새 기기로 보냅니다. (메일, 메신저, USB, 클라우드 폴더 등)
  2. 새 기기에서 앱 주소를 열어 설치하고, 비밀번호를 새로 설정합니다. (기기마다 따로 정합니다)
  3. 데이터 가져오기로 파일을 복원합니다.
  4. 홈·통계의 금액이 이전 기기와 같은지 확인한 뒤, 자동 백업과 백업 폴더도 새 기기에서 다시 설정합니다.

여러 기기에서 동시에 쓰고 싶다면

로컬 버전은 기기끼리 자동으로 합쳐지지 않습니다. 여러 기기에서 각각 입력하면 서로 다른 데이터가 생기고, 한쪽을 복원하면 다른 쪽 내용은 사라집니다. 아래 중 하나를 지키세요.

  • 입력하는 기기를 한 대로 정합니다. (권장) 다른 기기는 필요할 때 백업 파일을 복원해 조회만 합니다.
  • 여러 사람이 실시간으로 같은 데이터를 보고 입력해야 한다면 클라우드 동기화가 되는 원격 버전이 맞습니다. 개발자에게 문의하세요.
⚠️ 두 기기에서 따로 입력한 뒤 한쪽 백업을 다른 쪽에 복원하면, 복원 받은 기기에서만 입력했던 거래는 사라집니다. 합치는 기능은 없습니다.

18. 자주 묻는 질문

Q. 입력 버튼(＋)이 안 보이거나 눌리지 않아요.

열람 모드일 가능성이 큽니다. 설정 탭에서 로그인해 입력 모드로 전환하세요. 설정·명부·계정 탭에서는 ＋ 버튼이 원래 나타나지 않으니 홈에서 확인하세요.

Q. 어제까지 입력한 데이터가 다 사라졌어요.

먼저 어제와 같은 브라우저·같은 주소·같은 방식(탭/설치 앱)으로 열었는지 확인하세요. 시크릿 창이나 다른 브라우저에서는 빈 화면이 나옵니다. 그래도 없다면 브라우저 정리로 저장 데이터가 지워졌을 수 있으니, 가장 최근 백업 JSON을 데이터 가져오기로 복원하세요.

Q. 폰에서 입력했는데 PC에는 안 보여요.

정상입니다. 로컬 버전은 기기끼리 동기화되지 않습니다. 17장의 방법으로 백업 파일을 옮겨 복원하세요.

Q. 비밀번호를 잊어버렸어요.

찾을 방법이 없습니다. 4장의 "비밀번호를 잊어버렸다면" 순서로 초기화하고 백업을 복원하세요. 백업이 없다면 데이터를 되살릴 수 없습니다.

Q. 새 버전이 반영되지 않아요.

설정 → 앱 업데이트를 누르세요. 데이터는 유지됩니다. (그래도 업데이트 전에 백업을 권장합니다.) 그래도 같다면 앱을 완전히 종료한 뒤 다시 실행합니다.

Q. 헌금 입력 목록이나 일괄 입력에 '헌금'이 안 나와요.

수입 대분류의 이름이 정확히 헌금인지, 하위항목 사용이 켜져 있는지 확인하세요. (3장)

Q. 헌금 입력 목록에 교인이 안 나와요.

명부에 등록되지 않았거나 숨김 처리되었을 수 있습니다. 명부 탭의 숨김교인에서 해제하거나, 입력 화면의 안 쓰는 이름 숨기기 관리를 확인하세요.

Q. 일괄 입력 금액이 이상해요.

일괄 입력은 천원 단위입니다. 50000원은 50으로 입력해야 합니다.

Q. 자동 백업 파일이 안 만들어져요.

자동 백업은 월요일 정오 이후에 앱을 열어야 실행되고, 거래가 1건 이상 있어야 합니다. 설정에서 스위치가 켜져 있는지, 마지막 백업일이 언제인지 확인하세요. 폴더를 지정하지 않았거나 지정이 안 되는 기기라면 파일이 다운로드 폴더에 저장됩니다.

Q. 백업 메일 / 만기 알림 메일이 자동으로 발송되지 않아요.

서버가 대신 보내는 방식이 아닙니다. 메일 작성 화면이 열리면 보내기를 직접 눌러야 하며, 메일 앱이 없거나 설정이 안 된 기기에서는 열리지 않습니다. PC에서는 백업 파일을 직접 첨부해야 합니다.

Q. 기부금영수증에 직인이 안 찍혀요.

설정에서 직인 이미지(PNG, 2MB 이하)를 등록했는지 확인하세요. 직인과 교회 정보는 백업에 포함되므로, 복원 후에도 유지됩니다.

Q. 인쇄 용지는 무엇인가요?

통계, 월장부, 항목구조표, 기부금영수증은 A4 기준으로 출력됩니다.

Q. 문의는 어디로 하나요?

설정 탭 아래쪽 개발 항목에 표시된 개발자 이메일로 문의하세요.
